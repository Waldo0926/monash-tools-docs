Ed Web 是一个网页，把你的 Ed 论坛抓到你自己的浏览器里，可以搜索、看每个帖子的一句话概括，还能把整门课的课件打包成一个 zip 下载。没有后端，全部在标签页里运行。

<LinkCard title="打开 Ed Web" description="monashed.secureview.tech/app" href="https://monashed.secureview.tech/app/" />

## 怎么用

<Steps>

1. 打开 [monashed.secureview.tech/app](https://monashed.secureview.tech/app/)。
2. 输入你的 Ed 令牌，有两种方式：
   - **浏览器令牌**：在任意 Ed 页面打开浏览器控制台，运行 `copy(localStorage.authToken)`。大约 14 天过期，Ed Web 会显示还剩几天。
   - **API 令牌**：在 [Ed 设置](https://edstem.org/au/settings/api-tokens)创建，不会过期，可以随时撤销。浏览器能不能用取决于 Ed 的跨域设置；页面提示不能用的话，改用浏览器令牌。
3. 选要抓的课，点**开始抓取**。
4. 搜索、按分类浏览，看每个帖子下面的概括。搜索要求每个词都出现，回复也算。可以筛选**新内容**、**待解答**、**有提醒**、**老师已答**、**公告**、**有未读回复**、**我发的**和**收藏**。
5. 点 **↻ 刷新**，只重新抓指纹变了的帖子：更新时间、回复数或是否已答有变化。新帖和新回复标成**新**或 **+N 新回复**。
6. 打开**课程内容**，按模块看每门课的 lesson、完成状态，以及每节附带的 PDF 和链接。还会保存 Ed 阅读页正文和测验题，Ed 不给学生答案。可以筛选没开始、快到期、已过期或**有资料**的。
7. 点**一键下载资料**，得到一个按周分好文件夹的 zip，里面是这门课的 PDF 和链接。zip 是在你浏览器里生成的。
8. **导出 JSON** 存成文件，在另一台电脑首屏用**载入之前导出的 JSON**恢复。

</Steps>

## 概括是怎么来的

不用 AI。有老师回复的，取**最后一条**老师回复的前一两句，标上**老师答**；没有老师回复时取第一条像样的同学回答，标**同学答**；都没有才取帖子正文第一句。还会给截止或延期变更、时间地点变更、出分、考试安排打标签。开始时会标出没人回答的帖子和 48 小时内的新帖；刷新过一次后，**新**指上次刷新之后出现的内容。

## 隐私

- 令牌存在 `sessionStorage` 里，关掉标签页就没了。它只发给 Ed 自己的接口 `edstem.org`。
- 抓下来的帖子存在你浏览器的 IndexedDB 里，不会上传。本地另外只保存深浅色偏好，在 `localStorage` 里。
- [源代码公开](https://github.com/Waldo0926/ed-web)，可以自己核对它只访问 Ed 的接口和 Ed 的文件服务器。

<Aside type="caution">
Ed 令牌能做你账号能做的任何事，包括发帖。只粘贴到你信任的页面里，用完可以去 Ed 设置页删掉。
</Aside>

## Ed Web 还是 Study Kit？

Ed Web 不用装，任何电脑浏览器都能用。[Study Kit](/zh-cn/study-kit/) 在你电脑上同步一份，还包括 Moodle，并且能让 Claude 根据它回答问题。
