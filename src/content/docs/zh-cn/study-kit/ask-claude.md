直接用自己的话问。AI 是按意思挑工具的，不靠关键词，“这周有啥要交的”和“我是不是漏交了什么”都能用到待办。下面只是例子。

## 这周

| 可以问 | 它会查 |
| --- | --- |
| “这周我有什么要做的？” | 截止日期、可能漏交的作业、Ed 没做完的 lesson、最新公告 |
| “FIT2102 接下来两周有什么要交？” | Moodle 截止日期。Moodle 登录过期了也能查 |
| “我有没有漏交什么作业？” | 作业提交状态 |

## 课件

| 可以问 | 它会查 |
| --- | --- |
| “哪一周讲了 monad？在哪份讲义第几页？” | 全文搜索课件、课程笔记网页、Ed lesson 正文和录播字幕稿，带页码或时间戳 |
| “帮我看看 A2 的 spec 要求什么” | 找到 spec，只读需要的几页 |
| “FIT2109 第 5 周有哪些资料？” | 那一周的文件和链接 |
| “Moodle 上第 7 周的 workshop 在哪？” | 按名字找 Moodle 的章节和活动，给出链接。要先登录 Moodle |

## Ed

| 可以问 | 它会查 |
| --- | --- |
| “Ed 上有什么新消息？” | 上次看过之后的新帖和新回复 |
| “我上次问的问题有人回了吗？” | 你发的或关注的帖子 |
| “有没有人问过 A1 能不能用 lodash？” | 搜索帖子并读全文 |
| “带我过一遍 FIT2109 第 3 周的 pre-class” | 整节 lesson 按顺序：正文、阅读、PDF 和测验题 |
| “用第 3 周的测验题帮我复习” | Ed lesson 的测验题，一题一题来 |
| “看看我 FIT2109 的 lesson 进度” | 按 module 列出做完和没做完的 lesson |

## 成绩和消息

| 可以问 | 它会查 |
| --- | --- |
| “我 FIT2109 现在成绩多少？” | 总分、每项得分和反馈 |
| “FIT2102 最近有什么公告？” | Moodle 公告 |
| “Moodle 上有人给我发消息吗？” | Moodle 私信，只读 |

| --- | --- |
| “我学校邮箱里有什么要处理的？” | 最近还没读的收件箱邮件，推广和社交类已去掉 |

## 维护

| 可以问 | 会发生什么 |
| --- | --- |
| “帮我重新登录 Moodle” | 在你电脑上打开登录窗口 |
| “同步一下最新的” | 马上同步一次 |
| “monash 用不了了” | 跑一遍和 `monash doctor` 一样的检查 |

## 面板

从 1.4.0 开始，在支持 MCP Apps 的软件里，有三种回答还会附一个小面板：

- **待办**：问“这周我有什么要做的？”，会显示截止日期卡片和还没开始的 lesson。
- **Lesson 进度**：问“看看我 FIT2109 的 lesson 进度”，按 module 显示做完了几个。
- **测验练习**：问“帮我练一下 FIT2109 第 3 周的测验”，题目和选项可以直接点。做完点 **交给 AI 批改**，你的选择会发回对话，AI 根据 lesson 正文讲解。

答案在你点发送之前只留在面板里。不会提交到 Ed，也不会把 lesson 标成已完成。Ed 不给学生看标准答案，所以 AI 是根据 lesson 内容判断的，不确定的地方它会说明。

不支持面板的软件照样收到和以前一样的文字回答。面板能不能显示、按钮能不能发消息或打开链接，由各个软件决定。

## 预设提示

在 Claude 输入框的 **+** 菜单里，monash 有七个预设（其他软件会把 MCP 预设放在自己的位置，有的不显示）：功能大全、本周待办、Ed 新消息、找知识点、测验题复习、成绩和反馈、**作业要求**。给「作业要求」一个作业名，它会读 brief、rubric 和 Ed 上老师的回答，列出要交什么、怎么评分、截止时间和格式，以及 Ed 上的补充说明，每条注明出处。预设点了才发给 Claude，平时不占额度。

终端里运行 `monash help`，会列出每项功能、一句示例问法和对应命令。

## 作业问题按什么规则回答

先看 Moodle 上的 brief 和 rubric。Ed 上只认老师、助教的回复和他们 endorse 的回答，同学的回复只当线索。老师后来的更正优先；brief 和 Ed 说法不一致时，两边都列出并注明日期，建议去问老师，不替你选一边。每条要求都注明出处。

这条写在服务端说明里，用户不用做任何设置。

## 后台在做什么

AI 软件开着的时候，Study Kit 会：

- 每小时同步一次 Ed 和 Moodle（新帖、新回复、新课件），并更新搜索索引；
- 每 20 分钟给 Moodle 续一次期，因为 Moodle 空闲 4 小时就会把你登出。

## Moodle 登录过期了

关机或长时间睡眠后，Moodle 会话会过期。AI 会告诉你并问要不要登录，同意的话它会在你电脑上打开登录窗口；如果 Okta 还记得你，会在后台自动登录，连窗口都不弹。也可以自己运行 `monash login`。

登录过期期间，**截止日期照样能查**（用的是 Moodle 的日历订阅链接，不需要登录），Ed 不受影响。

## 它做不到

交作业、做测验、在 Ed 上发帖。这些请自己到网页上操作。邮箱操作和签到每一项都要你确认才执行。
