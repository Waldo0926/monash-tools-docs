`monash mcp` 是标准的本地（stdio）MCP 服务器，支持本地 MCP 的软件理论上都能接。先运行 `monash setup` 登录、选课，再接进你用的软件。

## 一条命令

```bash
monash connect cursor
```

可以写 `codex`、`cursor`、`vscode`、`windsurf` 或 `gemini`。它只在这个软件的配置文件里加 `monash` 这一项，写程序的完整路径，其他内容原样保留，改之前先备份。装了 `codex` 命令的话 Codex 用 `codex mcp add` 接。接好后重启软件。

```bash
monash connect                 # 列出所有软件和接入状态
monash connect vscode --print  # 只打印要加的配置，不改文件
monash connect cursor --remove # 移除
```

`monash connect` 要 Study Kit 1.2.0 以上。提示没有这个命令的话先运行 `monash update`。

`monash connect` 写的格式照各家 2026 年 10 月的官方文档。本地 Codex、Cursor、VS Code、Windsurf、Gemini CLI 连接尚未完成端到端实测，有出入时以官方文档为准。

配置文件里有注释的话（VS Code 允许写注释），`monash connect` 不会动它，会把要加的那段打印出来让你自己贴。想手动配置就按下面两步。

## 1. 找到 `monash` 的完整路径

很多软件读不到终端的 PATH，所以写完整路径最稳。

<Tabs syncKey="os">
  <TabItem label="macOS" icon="apple">
    ```bash
    which monash
    ```
    一般是 `/Users/你的用户名/.local/bin/monash`。
  </TabItem>
  <TabItem label="Windows" icon="seti:windows">
    ```powershell
    (Get-Command monash).Source
    ```
    一般是 `C:\Users\你的用户名\.local\bin\monash.exe`。写进 JSON 时反斜杠要写两遍（`C:\\Users\\...`），写进 TOML 时用单引号（`'C:\Users\...'`）。
  </TabItem>
</Tabs>

## 2. 加到你的软件里

把 `/full/path/monash` 换成你的路径。文件里已经有别的服务器的话，把 `monash` 这一项加进去，别覆盖整个文件。改完重启软件。

<Tabs>
  <TabItem label="Codex">
    运行 `codex mcp add monash -- /full/path/monash mcp`，或者编辑 `~/.codex/config.toml`（Codex CLI、ChatGPT 桌面版里的 Codex 和 IDE 插件共用）：

    ```toml
    [mcp_servers.monash]
    command = "/full/path/monash"
    args = ["mcp"]
    ```
  </TabItem>
  <TabItem label="Cursor">
    `~/.cursor/mcp.json`：

    ```json
    {
      "mcpServers": {
        "monash": { "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="VS Code">
    命令面板里选 **MCP: Open User Configuration**。注意外层是 `servers`，不是 `mcpServers`：

    ```json
    {
      "servers": {
        "monash": { "type": "stdio", "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="Windsurf">
    `~/.codeium/windsurf/mcp_config.json`：

    ```json
    {
      "mcpServers": {
        "monash": { "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="Gemini CLI">
    `~/.gemini/settings.json`：

    ```json
    {
      "mcpServers": {
        "monash": { "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
</Tabs>

## Agent skill

使用支持 skill 的 agent 时，可以这样安装 Study Kit 的 skill：

```bash
npx skills add Waldo0926/monash-study-kit
```

它把学习问题对应到 `monash` 命令，作业问题遵循同样的来源规则。登录、令牌和提交作业仍由你自己操作。使用前需要先安装 Study Kit 并完成设置。

## 注意

- 登录和选课还是用 `monash setup`。没装 Claude 的话，最后一步会提示找不到 Claude Desktop，忽略就行。
- 后台同步和 Moodle 续期只在软件开着、MCP 在运行时进行。
- ChatGPT 和 Codex 已通过远程集成验证只读课程查询；其他工作流和模型仍需分别验证。
- **ChatGPT，以及网页版、手机上的 Claude，需要一个 HTTPS 地址。** `monash mcp` 只在本机用。1.4.0 起包里带了可选的 `monash remote`，可以用自己的服务器和域名，也可以在自己电脑上开 Cloudflare 免费的临时隧道，见[自己托管](/zh-cn/study-kit/remote/)。
- 面板只在支持 MCP Apps 的软件里显示，其他软件照样收到文字回答。
