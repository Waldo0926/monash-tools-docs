[Monash Hub](https://monashhub.secureview.tech) 把平时要在 Handbook 和学校各个页面里翻的东西放在一起

每个答案都附来源链接和最后核对日期

界面有英文和简体中文

## 能做什么

| 想做 | 在哪 |
| --- | --- |
| 查一门课：校区、开课学期、考核、考试、先修、工作量<br />课程卡片用颜色标出有没有考试，并列出每项考核和比例 | 搜课号，或在**课程**页按条件筛选 |
| 找选修课<br />四种情况选一个：没列考试（绿）、只有小测（黄）、有考试（红）、待核实（灰）<br />可以再打开“无需先修课”“只看一年级”，也能在本科和研究生之间切换 | 首页的**找选修课**，或者打开 [monashhub.secureview.tech/electives](https://monashhub.secureview.tech/electives) |
| 看一门课在两个 Handbook 年份之间改了什么 | 课程搜索页的**比较年份**，或打开 [/units/compare](https://monashhub.secureview.tech/units/compare) |
| 找官方信息：WAM、特殊考虑、census date、签证、交换 | 搜关键词或直接问问题 |
| 看一个学位由哪些部分组成，哪些课你的校区其实不开 | **学位** |
| 按学期排课，每门课自动核对开课情况和先修<br />每年下面可以加夏季、冬季学期或十月入学，也能一次勾选好几门课加进去 | **选课规划**<br />排好以后可以打开**毕业准备清单**看看有没有漏掉的 |
| 往回看一门课需要先修什么，往后看它能解锁什么 | **先修图** |
| 算 WAM 或 GPA（马来西亚校区还有 CGPA） | **WAM/GPA 计算**<br />输入课号，或粘贴、截图 WES 成绩 |
| 查马来西亚每个课程的学费、按年还是整个课程，以及和 2026 年比的变化；也可以自己算算加上奖学金减免和生活费一共多少 | **马莫学费**，再点**自己估算学费、减免和生活费** |
| 查 census、退课截止、考试、出成绩、Allocate+ 和 WES 续注册日期 | 首页的**重要日期**，完整列表点**查看全部日期** |
| 给考虑马来西亚校区的家长看中文介绍：高考等各类学历的入学分数、雅思要求、学费、奖学金、转澳洲校区 | 页头的**给家长看** |
| 快速问个问题 | **提问**按钮<br />答案来自 Handbook、官网和同学帖子，也显示[马莫百科机器人](/zh-cn/wechat-bot/)的回答<br />机器人没有现成答案时，可能用免费模型从官方页面挑句子，每句都和来源逐字核对 |
| 看和分享同学经验 | **社区**<br />登录后可以发帖 |

选课规划、先修图和 WAM/GPA 计算都在页头的**选课工具**菜单里

找选修课页面上的都是按 Handbook 做的筛选，不是推荐

“没列考试”指考核项目里没有叫 exam 或 examination 的，期末考和期中考都算考试，quiz 和 test 单独算“只有小测”

一门课能不能算自由选修学分，要看你自己学位的要求

## 分清你看的是什么

| 标签 | 意思 |
| --- | --- |
| `Official Handbook` | 来自 Monash Handbook 的结构化数据 |
| `Official source` | 整理自 Monash 官网 |
| `Community` | 同学的提问和经验，不是学校政策 |

<Aside type="caution">
Monash Hub 不是 Monash University 运营的

选课、签证、考核和学术政策，请以链接里的官方页面、Moodle 或 WES 为准
</Aside>

## 你的数据

- **选课规划**只存在你的浏览器里  
  核对时会把规划发到服务器和 Handbook 比对，不保存  
  换设备时，在**更多**菜单点**复制规划码**  
  规划写在链接的 `#` 后面，浏览器不会把这部分发给服务器  
  在另一台设备打开链接，或用**粘贴规划码**  
  **导出**也还能保存文件
- **成绩**在你的浏览器里计算，只有课号会发到服务器，用来查学分和级别
- **课程评分**不用注册账号
