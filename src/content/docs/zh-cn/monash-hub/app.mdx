---
title: 把 Monash Hub 加到主屏幕
description: 在 iPhone、安卓或电脑上像 App 一样安装 Monash Hub。看过的页面没网也能看。
---

import { Tabs, TabItem, Steps, Aside } from '@astrojs/starlight/components';

Monash Hub 可以放到手机主屏幕上，点图标就像 App 一样打开。看过的课程和指南没网也能打开，不用去应用商店下载。

<Tabs syncKey="device">
  <TabItem label="iPhone 和 iPad">
    <Steps>

    1. 用 **Safari** 打开 [monashhub.secureview.tech](https://monashhub.secureview.tech)，点**分享**（带箭头的方框）。看不到的话先点地址栏旁的 **···**。
    2. 在菜单里找到**添加到主屏幕**。
    3. 点**添加**。

    </Steps>
  </TabItem>
  <TabItem label="安卓">
    <Steps>

    1. 打开网站，点浏览器菜单（**⋮** 或 **≡**）。
    2. 选**添加到主屏幕**或**安装应用**。华为、小米、OPPO、vivo 自带的浏览器可能叫**添加到桌面**。
    3. 没反应的话，在手机设置里允许浏览器创建桌面快捷方式。

    </Steps>
  </TabItem>
  <TabItem label="电脑">
    Chrome 或 Edge 里点地址栏右边的安装图标。Mac 上的 Safari 选**文件**，再选**添加到程序坞**。
  </TabItem>
  <TabItem label="在微信里">
    微信不能把网站加到主屏幕。点右上角 **···**，选**在浏览器打开**或**在 Safari 中打开**，再按你手机的步骤操作。
  </TabItem>
</Tabs>

<Aside>
没网时 Monash Hub 会显示保存的版本，并提示内容可能不是最新的。
</Aside>
