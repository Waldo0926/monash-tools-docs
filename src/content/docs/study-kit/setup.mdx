The installer starts this for you. To run it again later:

```bash
monash setup
```

Follow the prompts. There are four steps.

<Steps>

1. **Ed.** It opens Ed's [API token page](https://edstem.org/au/settings/api-tokens). Click **Create Token**, name it anything, copy the token and paste it back into the terminal. Nothing shows while you paste; that is normal. The token does not expire. Delete it on the same page whenever you want to cut access. If your units don't use Ed, press Enter to skip, then answer yes to "not using Ed".

2. **Moodle.** It opens a **separate browser window**. Log in to Monash as usual with Okta and MFA. The window closes by itself once you are in. This window has its own profile and is isolated from your everyday browser. Study Kit only takes the Moodle session from it and never reads your normal browser.

3. **Units.** It tracks this semester's units by default. You can pick your own instead.

4. **Connect your AI app.** It adds `monash` to Claude Desktop and Claude Code by itself.
   - On macOS it quits Claude Desktop first (Claude overwrites config changes made while it runs), then opens it again.
   - On Windows it asks you to **fully quit** Claude Desktop first: tray icon at the bottom right, right-click, **Quit**.
   - Using Codex, Cursor, VS Code, Windsurf or Gemini CLI instead? If this step says it cannot find Claude Desktop, ignore it. After setup, run `monash connect codex` (or `cursor`, `vscode`, `windsurf`, `gemini`) and restart that app. Details on [Other AI apps](/study-kit/other-clients/).

</Steps>

At the end you can sync straight away. The first sync downloads every course file and takes from a few minutes to about a quarter of an hour.

## Check it in your AI app

- **Claude Desktop**: in the chat box, under **+** then **Connectors**, you should see **monash**. Leave it on.
- **Codex, Cursor and others**: run `monash connect` to see which apps have monash, then check the app's MCP or tools list.

Then ask "What's due this week?".

<Aside type="tip">
Not showing up? See [Troubleshooting](/study-kit/troubleshooting/#monash-does-not-show-up-in-your-ai-app).
</Aside>

## Optional: school mail and attendance

Once setup is done you can also connect your Monash mail and attendance. Just say "connect my school email" or "connect my attendance" in your AI app; it installs what is missing and opens the sign-in window. See [School mail and attendance](/study-kit/mail-attendance/).

## Redo one step

| To redo | Run |
| --- | --- |
| Moodle login | `monash login` |
| Ed token | `monash login ed` |
| Pick units again | `monash courses` |
| Connect to Claude again | `monash setup claude` |
| Connect another AI app | `monash connect codex` (or `cursor`, `vscode`, `windsurf`, `gemini`) |
| School mail / attendance login | `monash gmail login` / `monash attendance login` |
| My units don't use Ed | `monash config use_ed false` |
