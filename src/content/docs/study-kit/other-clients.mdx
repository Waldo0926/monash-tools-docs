`monash mcp` is a standard local (stdio) MCP server, so any app that supports local MCP servers should work. Run `monash setup` first to sign in and pick units, then connect your app.

## One command

```bash
monash connect cursor
```

Use `codex`, `cursor`, `vscode`, `windsurf` or `gemini`. It adds only the `monash` entry to that app's config file, with the full path to the program, keeps everything else and saves a backup first. For Codex it uses `codex mcp add` when the `codex` command is installed. Restart the app afterwards.

```bash
monash connect                 # list apps and which are connected
monash connect vscode --print  # show the entry without changing anything
monash connect cursor --remove # take it out again
```

`monash connect` needs Study Kit 1.2.0 or later. Run `monash update` if it says the command does not exist.

<Aside>
**Claude Desktop** and **Claude Code** have been tested with the local server. **ChatGPT** and **Codex** have also been verified with read-only course queries through a private remote integration using the **v1.3.0** core; Codex successfully queried both Moodle and Ed. These remote checks do not test `monash connect codex` or every Codex interface.

That check ran on one machine without a public domain. Separately, ChatGPT Plus works with the author's own domain and server; see [Host it yourself](/study-kit/remote/).

`monash connect` writes the format from each vendor's docs as of October 2026. The local Codex, Cursor, VS Code, Windsurf and Gemini CLI connections have not yet been tested end to end; if the formats differ, the vendor's docs win.

If your config file has comments (VS Code allows them), `monash connect` leaves it alone and prints the entry for you to paste. To do it by hand, follow the two steps below.

## 1. Find the full path of `monash`

Many apps do not read your terminal's PATH, so use the full path.

<Tabs syncKey="os">
  <TabItem label="macOS" icon="apple">
    ```bash
    which monash
    ```
    Usually `/Users/<you>/.local/bin/monash`.
  </TabItem>
  <TabItem label="Windows" icon="seti:windows">
    ```powershell
    (Get-Command monash).Source
    ```
    Usually `C:\Users\<you>\.local\bin\monash.exe`. In JSON, double every backslash (`C:\\Users\\...`). In TOML, use single quotes (`'C:\Users\...'`).
  </TabItem>
</Tabs>

## 2. Add it to your app

Replace `/full/path/monash` with your path. If the file already lists other servers, add the `monash` entry instead of replacing the file. Restart the app afterwards.

<Tabs>
  <TabItem label="Codex">
    Run `codex mcp add monash -- /full/path/monash mcp`, or edit `~/.codex/config.toml` (shared by Codex CLI, the ChatGPT desktop app's Codex and the IDE extension):

    ```toml
    [mcp_servers.monash]
    command = "/full/path/monash"
    args = ["mcp"]
    ```
  </TabItem>
  <TabItem label="Cursor">
    `~/.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "monash": { "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="VS Code">
    Command Palette, then **MCP: Open User Configuration**. The outer key is `servers`, not `mcpServers`:

    ```json
    {
      "servers": {
        "monash": { "type": "stdio", "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="Windsurf">
    `~/.codeium/windsurf/mcp_config.json`:

    ```json
    {
      "mcpServers": {
        "monash": { "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="Gemini CLI">
    `~/.gemini/settings.json`:

    ```json
    {
      "mcpServers": {
        "monash": { "command": "/full/path/monash", "args": ["mcp"] }
      }
    }
    ```
  </TabItem>
</Tabs>

## Agent skill

For an agent that uses skills, install the Study Kit skill with:

```bash
npx skills add Waldo0926/monash-study-kit
```

It maps study questions to `monash` commands and carries the same source rules for assignment questions. Logins, tokens and submitting work stay with you. The skill needs Study Kit installed and set up first.

## Good to know

- Sign in and pick units with `monash setup` as usual. Without Claude installed, the last step says it cannot find Claude Desktop. Ignore it.
- Background sync and Moodle refresh only run while the app is open and the MCP server is running.
- Read-only course queries have been verified in ChatGPT and Codex through the remote integration; other workflows and models still need their own checks.
- **ChatGPT, and Claude on the web or phone, need an HTTPS address.** `monash mcp` is local only. From 1.4.0 the package includes an optional `monash remote` mode. Use your own server and domain, or a free Cloudflare quick tunnel on your own computer. See [Host it yourself](/study-kit/remote/).
- Panels only show in apps that support MCP Apps. Other apps get the same text answers.
