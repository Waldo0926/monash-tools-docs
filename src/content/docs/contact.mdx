## A tool isn't working, or you want a feature

The best way is to [open a GitHub issue](/about/#report-a-problem-or-ask-for-a-feature). Other students with the same problem can see the fix too.

## You don't use GitHub, or want to ask privately

Message me on WhatsApp or WeChat. If you don't use WeChat, WhatsApp is fine. Tell me which tool you're using and where you got stuck, and I'll reply sooner.

## Before you message me

- Don't send me your Ed token, Moodle or Okta password, or login cookies. I will never ask for them. Cover them up in screenshots.
- Report security problems privately, not in a public issue.
- These are my own tools, not official Monash ones. For anything formal, ask the university.
