Study Kit

Study Kit 把 Monash 的 Moodle 和 Ed 接进你电脑上的 AI：Claude、Codex（ChatGPT 桌面版里也有）、Cursor 等。装好后直接问：

  • “这周我有什么要交的？”：Moodle 截止日期、可能漏交的作业、Ed 上没做完的 lesson、最新公告。
  • “Ed 上有什么新消息？我上次问的问题有人回了吗？”
  • “FIT2102 哪一周讲了 monad？在哪份讲义第几页？”
  • “A2 的 spec 要求什么？”“我 FIT2109 现在成绩多少？”
  • “用 FIT2109 第 3 周的测验题考考我。”支持 MCP Apps 面板的软件里，待办、Ed lesson 进度和测验题会显示成能点的小面板。
  • 1.5.0 新增，可选：“我学校邮箱里有什么要处理的？”“哪节课还没签到？”见学校邮箱和考勤。

答案来自你真实的 Moodle 和 Ed 数据，还会给出处，比如“Workshop 5 Slides 第 25 页”。AI 自己找到那份文件、只读需要的几页，你不用下载 PDF 再上传。

两个部分

Section titled “两个部分”
  • MCP 服务器给 AI 用。 Moodle 和 Ed 都要 Okta 和 MFA，AI 自己进不去。有了它，AI 可以在聊天中途自己去查。
  • monash 命令给你用。 只有人该做的事（安装、过 MFA、粘贴 Ed 令牌）由它来做；AI 额度用完时也能直接用，monash todo 大约一秒出结果。

它不会做的事

Section titled “它不会做的事”

对 Moodle 和 Ed 只读。不会交作业、做测验或在 Ed 上发帖。可选的学校邮箱和考勤可以帮你起草邮件、改标签、签到，每一项都要你确认才执行。课件、登录状态和数据库都在你电脑上，不经过任何第三方服务器。

你需要

Section titled “你需要”
  • 一台电脑（macOS、Windows 或 Linux）。默认情况下手机上的 AI App 用不了：它们只能连网上的 MCP 服务器，而 Study Kit 跑在你电脑上，登录信息才能只留在你这。想在 ChatGPT 或网页版、手机上的 Claude 里用，可以用自己的服务器或 Cloudflare 免费隧道给它一个 HTTPS 地址。
  • 支持本地 MCP 的 AI 软件。Claude Desktop（下载）和 Claude Code 已实测本地接入；ChatGPT 和 Codex 也已通过使用 v1.3.0 核心的私有远程集成验证只读课程查询。Codex、Cursor、VS Code、Windsurf、Gemini CLI 支持本地一键配置，接入方式和实测范围见其他 AI 软件。1.4.0 起还可以自己开可选的远程模式，让 ChatGPT 和网页版、手机上的 Claude 也能用，见自己托管。
  • Chrome、Edge 或 Brave 其中一个，只用来打开 Moodle 登录窗口。Windows 自带的 Edge 就行。
  • Monash 账号。

注意

时间默认按 UTC+8 处理。澳洲校区运行 monash config tz_offset 10（夏令时用 11）。

开始

Section titled “开始”
安装macOS 或 Windows，一条命令。
第一次设置Ed 令牌、Moodle 登录、选课、接进 AI 软件，大约五分钟。
可以问 AI 什么每类事情的示例问法。
不用 AI 也能查在终端里看同样的结果，不耗额度。
学校邮箱和考勤1.5.0 起可选，在 AI 里说一声就能接上。
